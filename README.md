# WELCOME TO THE CANzone

> The best CAN you'll ever try

Como rodar:

Na raiz do projeto, rode: `python main.py`

em seguida, rode:  `python server.py`

Conecte o celular e o laptop na mesma rede WI-FI
use `ipconfig` ou `ifconfig` no shell para obter o endereço de IP do adaptador WI-FI da máquina. <br/>
No navegador do celular, digite : `http:<ip_do_laptop>:5000`
